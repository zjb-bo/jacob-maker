从链接到作品，只需三步

  1. 填写链接

    标题、简介和截图自动读取，也可以先补充你自己的介绍。

  2. 确认发布

    在 GitHub 提交已填好的请求。只有仓库主人提交的请求会被处理。

  3. 等待上线

    通常需要 1–3 分钟。成功后请求会自动关闭并附上网站链接；失败会显示原因，可修正后重新提交。
